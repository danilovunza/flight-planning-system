# Flight Planning System

## Overview

The Flight Planning System is a Python application that simulates core airline flight planning operations.

The system performs:

* Route Planning
* Fuel Planning
* Weight & Balance Analysis
* Weather Assessment

---

## Features

* Flight Route Calculation
* Fuel Planning
* Weight & Balance
* Weather Data
* Aircraft Performance Checks

---

## Classes

### Aircraft

Stores aircraft specifications.

### Airport

Stores airport information.

### Flight

Stores route information.

### FuelPlanner

Calculates fuel requirements.

### WeightBalance

Calculates aircraft loading.

### Weather

Stores weather information.
